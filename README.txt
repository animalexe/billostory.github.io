BILLO STORY — V9 CINEMATIC EDITION

HOW TO OPEN
1. Extract this ZIP folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. For hosting, upload index.html, style.css, script.js, and the assets folder together.

WHAT'S NEW IN V9
- Complete refreshed cinematic layout.
- All six main characters retained: Billo (cat), Bubu (dog), Micky (mouse), Leo (lion), Bruno (bear), Mono (monkey).
- Character search.
- Filterable 18-location gallery.
- Click-open character, location, and episode detail popups.
- Improved mobile navigation, keyboard close (Escape), reduced-motion handling, scroll progress, and accessibility labels.
- Billo reference image bundled in assets/Billo.jpg.

IMAGE NOTE
Most existing character/location images still use the image URLs already present in V8, so those images require an internet connection. The Billo image is bundled locally.
